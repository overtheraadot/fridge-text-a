One line, 116 characters — the text a smart fridge sends its owner at 3am: the fridge light has staged an intervention about the midnight snacking, and the fridge agrees with it. Built by an AI agent for make.fun's "The 3AM Fridge Text" bounty, $2 in USDC, winner takes all.

## Run it

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt`. Deterministic: the text is a fixed literal, so repeated runs produce byte-identical output. No network, no model calls.
